## Purpose

定义 example 接入 SDK 4.1.0 后的可重复集成验收边界，确保新增只读机型查询能够经过实际 SDK 完成开放接口调用，且测试报告清晰区分本地桩验证、演示降级和真实环境联调。

## ADDED Requirements

### Requirement: SDK 版本一致性与兼容性
example MUST 使用统一的 4.1.0 SDK 模块，并保持既有机器人查询、讲解、任务闭环及实时接口的兼容性。

#### Scenario: 升级验收
- **WHEN** 对 SDK 4.1.0 同步结果执行验收
- **THEN** SDK 模块版本一致，后端编译与测试、前端测试与生产构建均成功

### Requirement: 新增能力通过真实 SDK 集成验证
集成验收 MUST 从 BFF HTTP 入口经过真实 SDK 到可控 HTTP 上游，验证机型查询路径、参数编码、完整响应、可空字段和失败语义，不以 SDK 客户端替身代替调用链。

#### Scenario: 完整查询链路
- **WHEN** 测试客户端通过 BFF 查询有效机型
- **THEN** 上游收到 `GET /api/open/v1/robot-model` 及原始 modelCode，客户端收到完整详情及文件字段

#### Scenario: 无效输入与上游错误
- **WHEN** 输入缺失或空白，或上游返回业务错误或 HTTP 失败
- **THEN** 客户端收到错误响应，且无效输入不触发上游请求

### Requirement: 验证结果可追溯
验证报告 MUST 分别记录本地集成、前后端回归及真实环境只读联调的命令、结果或缺失条件，且不得泄露密钥和签名。

#### Scenario: 无真实环境条件
- **WHEN** 测试环境、凭据或有效机型编码不可用
- **THEN** 报告将真实联调标为未执行并说明条件，不用本地桩或 mock 结果替代

#### Scenario: 真实环境查询
- **WHEN** 已具备授权测试环境、凭据及有效机型编码
- **THEN** 执行只读查询并记录脱敏结果，明确验证来源且不下发机器人操作指令
